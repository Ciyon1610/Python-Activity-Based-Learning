# Student Marks and Grade Calculator

Video reference project: a beginner Python program that reads a student's name and five subject marks, calculates total and average, then assigns a letter grade. This example is separate from the ten selected difficult case studies.

## Run

```bash
python student_marks_grade_calculator.py
```

Assumptions: marks are valid numbers from 0 to 100; the program uses five subjects. Grade thresholds are A: 90+, B: 80+, C: 70+, D: 60+, E: 50+, and F: below 50.

See [test_cases.md](test_cases.md) for sample cases and [sample_output.txt](sample_output.txt) for a sample run.
